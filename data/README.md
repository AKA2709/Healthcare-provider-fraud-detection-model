```

│   ├── Train_data.csv   # Training data with labels
│   ├── Test_data.csv    # Test data (labels withheld for Kaggle competition)
```

2. Click "Download"
3. Extract to `raw/` folder

## Dataset Overview

### Features (from Kaggle)
- **Inpatient Claims:** Procedure codes, diagnosis codes, claim amount, duration
- **Outpatient Claims:** Service date, reimbursement, provider
- **Beneficiary Data:** Age, gender, state, county
- **Target:** `PotentialFraud` (binary: 0=legitimate, 1=fraud)

### Key Statistics
- **Size:** ~40,000 inpatient claims
- **Features:** ~50 raw features
- **Fraud Rate:** ~5% (imbalanced)
- **Time Period:** Historical CMS-style data (2008-2010 era)

### Data Quality Notes
- ✓ No personally identifiable information (synthetic/anonymized)
- ✓ Complete records (minimal missing values)
- ✓ Public dataset (Kaggle open-source)
- ⚠️ Synthetic data patterns may differ from real fraud

## Feature Descriptions

### Engineered Features (created in pipeline)

| Feature | Type | Description |
|---------|------|-------------|
| `claim_amount_quantile` | int | Percentile rank (0-10) of claim within provider |
| `claim_amount_zscore` | float | Z-score of claim amount (outlier detection) |
| `provider_fraud_rate` | float | Historical fraud % for this provider |
| `state_fraud_prevalence` | float | Fraud rate in provider's state |
| `age_group` | categorical | Binned age (young/middle/senior/elderly) |
| `gender` | int | Binary (M=1, F=0) |
| `provider_procedure_diversity` | int | Number of unique procedures by provider |
| `provider_diagnosis_diversity` | int | Number of unique diagnoses by provider |
| `days_since_discharge` | int | Time from discharge to claim |
| `inpatient_outpatient_ratio` | float | Mix of claim types |

## Dataset Limitations

1. **Synthetic Data:** Not real fraud patterns
   - Real fraud may have different characteristics
   - Model needs retraining on real fraud labels

2. **Time Period:** 2008-2010 era data
   - Fraud techniques evolve
   - May not capture modern fraud schemes

3. **Fraud Definition:** Whatever CMS labeled as fraud
   - Definition may differ from your organization
   - Consider labeling own data for better transfer

4. **Geographic Bias:** May over-represent certain regions
   - Check for fairness/disparate impact by state
